# Governance

This repository contains public-release material published by SINTELRA under the DGCP™ Framework.

## Repository Purpose

The purpose of this repository is to maintain selected SINTELRA material approved for public access.

Content may include:

- Public Articles
- Public Signals
- Brief Notes
- Selected Research Notes
- Selected analytical publications

## Publication Principles

Material published through this repository should:

- be appropriate for public access;
- remain evidence-grounded and proportionate to available evidence;
- distinguish evidence, analysis, uncertainty, and interpretation;
- use traceable sources where required;
- comply with applicable SINTELRA publication standards.

## Evidence Discipline

SINTELRA publications should avoid:

- unsupported factual claims;
- unsupported forecasting;
- presenting scenarios as predictions;
- overstating certainty;
- presenting inference as established fact.

## Source and Citation Standard

Where citations are required, SINTELRA uses numeric citations in body text:

[1]  
[2]  
[3]

References should preserve canonical English organization, author, and source names.

Reference entries should include the source URL where appropriate.

Translated, localized, duplicate, or parenthetical source-name labels should not be added to references.

## Public Boundary

This repository contains only material designated for public release.

Publication of selected outputs does not imply disclosure of underlying research materials, internal documentation, protected methodology, or non-public systems and records.

## Change Control

Repository changes should be made through identifiable commits with clear commit messages.

Previously published material should not be silently altered in ways that materially change its meaning.

Material corrections, replacements, or status changes should remain traceable through repository history.
